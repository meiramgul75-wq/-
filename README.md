# DAIRN Name Generator

Небольшой консольный генератор имён для миров вселенной DAIRN.

При каждом запуске программа выводит пять случайно составленных названий. Имя собирается из трёх наборов слогов, которые находятся в `src/main/kotlin/Main.kt`.

## Запуск

Требуется JDK 21.

```bash
./gradlew run
```

Либо откройте `Main.kt` в IntelliJ IDEA и нажмите кнопку запуска рядом с `main`.

## Пример вывода

```text
Генератор имён вселенной DAIRN
-------------------------------
1. Норсейир
2. Аэлор
3. Даймара
```
