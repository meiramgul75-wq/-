# DAIRN Name Generator

Небольшой консольный генератор имён для миров вселенной DAIRN.

При каждом запуске программа выводит по одному случайно составленному названию на английском, русском и казахском языках. Логика генерации находится в `src/main/kotlin/kz/nordpos`.

## Запуск

Требуются JDK 21 и доступ к интернету при первом запуске: Gradle загрузит необходимые зависимости.

```bash
./gradlew run
```

Либо откройте `Main.kt` в IntelliJ IDEA и нажмите кнопку запуска рядом с `main`.

## Пример вывода

```text
Генератор имён вселенной DAIRN
-------------------------------
Английское: Calenara
Русское:    Велория
Казахское:  Көренер
```
